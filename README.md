# ペンギンマップ 🐧

日本でペンギンに会える施設（109施設・12種）を、実際の地図の上に表示する Web アプリ。

## できること
- **地図**：国土地理院の地図（淡色・標準・航空写真）と OpenStreetMap を右上で切り替え。県境を太線で描き、行った県＝濃い青／まだの県＝薄い青／施設なし＝灰色
- **県ごと→施設ごと**：引いて見ると県名と施設数のバッジ、拡大するとペンギンのピン（近い施設は「○か所」にまとまる）。県をタップすると県内の施設一覧、×で閉じると県全体を表示
- **施設の詳細**：所在地の目安、「公式」「Google」「ペンギン写真」ボタン、アクセス（電車・バス／車）と現在地からの経路、会えるペンギン（4列の写真、タップで説明のポップアップ）
- **写真**：Wikimedia Commons の実写真（ポップアップから出典へ）。Google画像検索へのリンクもあり
- **行ったところの記録**：「行った！」ボタン、★1〜5の評価、訪問日、感想メモ。行った施設のピンは青く塗られて✓
- **絞り込み**：施設名・都道府県での検索、種類での絞り込み（複数選ぶと、その全部がいる施設だけを表示）、行った／未訪問
- **一覧**：右上の「一覧」から都道府県順のリストを表示。記録の書き出し・読み込み（バックアップ用）もここから

記録はこのブラウザの localStorage に保存される（別の端末とは同期しない）。

## 公開中のページ（iPhoneのホーム画面に追加して使う）
https://sypsypclaude.github.io/penguin-map/ （GitHub Pages・誰でも見られる公開ページ。記録は各端末の中だけ）

更新するとき：ファイルを直したら `sw.js` の `VERSION` を1つ上げてから commit → `git push`。1〜2分で反映され、iPhoneではアプリを開き直すと新しい版になる。

## 起動（PCで試す）
```
npx http-server penguin-list -p 8765
```
→ http://localhost:8765 を開く（`index.html` を直接ダブルクリックで開いても動く）

## ファイル
- `index.html` / `css/style.css` / `js/app.js` … 本体（Leaflet + leaflet.markercluster を CDN から読み込む）
- `data/facilities.js` … 施設データ（名前・都道府県・種類・公式URL・座標）
- `data/species.js` … ペンギン12種の説明と写真の出典
- `data/prefs.js` … 都道府県の境界線（出典：地球地図日本（国土地理院）。[dataofjapan/land](https://github.com/dataofjapan/land) の japan.geojson を mapshaper で 8% に簡略化）
- `img/species/` … 種ごとの写真（Wikimedia Commons、CC BY-SA など。出典は species.js の `credit`）

## データについて（要注意）
- 施設一覧は 2026年11月に以下を突き合わせて作成：
  - ペンギン・ポスト「ペンギンに会える水族館・動物園」 https://penguin-pub.com/aquarium_zoo_list （日付なし）
  - いきものアカデミー「ペンギンがみられる全国の施設」（2018〜2019年の記事、一部2023年更新）
- 2つの情報源で種類が食い違う施設がある。大きい水族館で片方が1種だけになっている場合は、種類が多い方を採用した（例：海響館・八景島・仙台うみの杜）。上野動物園はフンボルトのみとした
- 閉館済みとみられる施設（京急油壺マリンパーク、志摩マリンランド、みさき公園、丹後魚っ知館）は除外
- アクセスは各施設の公式サイトのアクセス案内を要約。公式サイトから読み取れなかった30施設は観光ガイドサイト（るるぶ・ウォーカープラスなど）の情報を使った（各施設の出典リンク参照）
- 志布志湾大黒イルカランドは宮崎県串間市（鹿児島県ではない）
- 公式サイトが確認できなかった8施設は、「公式サイトを検索」（Google検索）へのリンクにしている
- 座標は OpenStreetMap で検索した値と手動での補正。数百m程度ずれることがある
- 飼育しているペンギンは入れ替わるので、正確な情報は各施設の公式サイトで確認すること
